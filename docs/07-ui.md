# 07 · UI

## Mockup

(Artboards "RERUN · LIBRARY" and "RERUN · GAME DETAIL", clickable in play mode.)

## Window

- Frameless with its own title bar (40 px): logo, `rerun`, `BY MYTHEN STUDIOS`, window buttons.
- Sidebar: Library · Applied · Topos · Log · Settings; at the bottom "Your system" (GPU, driver, CPU threads, OS).
- Status bar: version · "No background process · Topo index <version> · signature verified".

## Screens

**Library** – table: game (+ short info), source, graphics API, status, "Details". Filters: All / Fix available / Applied / Heuristic. Search, "Rescan".

**Game detail** – header with AppID, exe, graphics API, Topo revision. Three tabs:
- *Recommended*: problems on your system, per problem variants with evidence status, source linked directly, slot conflicts visible. Passed checks collapsed ("OK"). Tips and launch options.
- *Manual*: CPU affinity (grouped by topology, presets from the system), launch method, priority, compatibility mode and flags, firewall, launch options (copy / add to Steam only while Steam is closed), wrappers & tools (matching the graphics API, slot check).
- *Installed*: every change as a row with details and "Remove"; "Reset everything", "Check folder"; shared dependencies with "needed by".

Always on the right, the panel: *Preview* (what happens, admin yes/no, backup) → "Apply" / "Discard". In the Installed tab: how removal works.

**Log** – all changes across all games in chronological order, filterable, each individually reversible. Results of the post-launch check ("Affinity active", "reset by upc.exe").

**First launch** – scan of the libraries, system profile, explanation in three sentences: nothing in the background, everything reversible, only verified sources.

## Design system

Mythen Studios, theme "Night". Status always as symbol + word.

## Copy

Base English, German as the second language. Tone: calm, direct, concise, informal "du" (in German). No superlatives, no exclamation marks.
